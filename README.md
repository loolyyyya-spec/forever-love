## Overview

Forever Love is an interactive digital Valentine's Day card built with modern web technologies. This engaging single-page application features a beautifully animated envelope that users can open to reveal a special message. The experience includes smooth animations, a password protection feature, and a responsive design that works across all device sizes.

## ✨ Features

- 🎨 **Beautiful Animations**: Smooth, engaging animations using Framer Motion
- 🔒 **Password Protection**: Secure your special message with a password
- 📱 **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- 🎨 **Modern UI**: Clean, elegant design with a romantic color scheme
- ⚡ **Blazing Fast**: Built with Vite for optimal performance
- 🔄 **Interactive Elements**: Clickable components with visual feedback

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/iging/forever-love.git
   cd forever-love
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and visit `http://localhost:5173`

## 🛠️ Building for Production

To create a production build:

```bash
npm run build
# or
yarn build
```

The production build will be available in the `dist` directory.

## 🎨 Customization

### Changing the Theme

Edit the color scheme in `tailwind.config.js` to match your preferred Valentine's Day palette.

### Modifying the Message

Update the message content in the `MessageContent` component.

### Setting a Password

Modify the password logic in the `PasswordScreen` component.
